# Deepika & Subham — Ashirvad Ceremony V4

New feature: **Personalised invitation PDF**. Guests tap Download your personalised invitation, enter their name, and download a PDF addressed to them. PDF generation uses html2pdf.js from a CDN, so the visitor needs an internet connection.

The site remains a static GitHub Pages site. Other features: palace door entrance, English/Bengali selector, falling petals, confetti/fireworks on taps, photo placeholders, family message, WhatsApp RSVP/share, Google Calendar, countdown, and local-demo guestbook/counter.

Important: Guestbook and RSVP click count are browser-local, not shared across visitors. Couple photo placeholders can be replaced when photos are supplied. Wedding date remains “coming soon”.
